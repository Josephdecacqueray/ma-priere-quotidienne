Polices de l'application « Ma prière quotidienne »

La police « Shelley Volante Script » n'a pas été trouvée localement lors de la création du prototype.
La police calligraphique libre « Great Vibes » (GreatVibes-Regular.ttf) est donc utilisée provisoirement en secours hors-ligne.

Pour activer « Shelley Volante Script » :
1. Copiez votre fichier de police dans ce dossier `./fonts/` sous l'un des noms suivants :
   - `./fonts/ShelleyVolanteScript.ttf`
   - `./fonts/ShelleyVolanteScript.otf`
2. Poussez la modification sur GitHub (ou rechargez le site) :
   le CSS (`css/styles.css`) est déjà configuré avec `@font-face` sur ces chemins en priorité.
